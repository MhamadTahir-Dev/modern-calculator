# 🧮 Modern Calculator App

A feature-rich, clean, and responsive Calculator web application built from scratch using **Vanilla JavaScript**, **HTML5**, and **CSS3**. 

## ✨ Features
- **Core Operations**: Addition, subtraction, multiplication, division, and percentage calculations.
- **Advanced Logic**: Supports chained calculations without pressing equals repeatedly.
- **Smart Validation**: Prevents multiple decimal points and handles division by zero errors gracefully.
- **Memory & Delete**: Clear (`C`) and Backspace (`⌫`) functionalities.
- **Modern UI & UX**: Sleek interface designed with CSS gradients and responsive layouts.

## 🛠️ Built With
- **HTML5** & **CSS3** (Flexbox, CSS Variables, Gradients)
- **Vanilla JavaScript (ES6+)**
- **DOM Manipulation & Event Delegation**

## 💻 How to Run Locally
1. Clone or download this repository to your local machine.
2. Open the `index.html` file in your preferred web browser.
